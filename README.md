# text_analysis
Анализ текстов на Python. Классификкация, кластеризация

Вариант А: Mini-Batch K-Means (Заданное число кластеров $K$)Классический K-Means требует пересчета расстояний от всех $N$ точек до всех $K$ центроидов на каждой итерации, что медленно для 100 000+ записей. Mini-Batch K-Means решает эту проблему оптимизацией:Инициализация: Случайным образом выбираются $K$ векторов из корпуса, которые становятся начальными центрами кластеров (центроидами).Итерации по батчам:Из 100 000 векторов выбирается случайная подвыборка (батч, например, 2 000 векторов).Для каждого вектора из батча находится самый близкий центроид (с максимальным значением dot).Центроид смещается в сторону нового вектора пропорционально скорости обучения ($\eta = \frac{1}{\text{count}}$).Разметка: После завершения итераций обучения все 100 000 векторов распределяются по итоговым сформированным центроидам.

Вариант Б: Leader / Canopy Clustering (Автоматическое число кластеров)Используется, когда число тем заранее неизвестно:Берётся первый вектор из датасета и объявляется центроидом Кластера №0.Берётся следующий вектор и сравнивается со всеми созданными центроидами.Если максимальное косинусное сходство $\ge$ threshold (например, $0.35$), вектор добавляется к этому кластеру.Если сходство со всеми центроидами ниже threshold, этот вектор объявляется новым центроидом (создается новый кластер).5. Интерпретация результатов и визуализацияТоп N-грамм для каждого кластера (print_top_ngrams):Центроид кластера — это усредненный TF-IDF вектор всех входящих в него документов. Чтобы понять тему кластера, алгоритм берет его центроид, сортирует признаки по убыванию веса TF-IDF и переводит их числовые индексы обратно в понятные человеку слова и буквенные сочетания (inv_vocab).Визуализация (plot_clusters_distribution):Подсчитывается количество документов в каждом кластере и строится гистограмма с помощью matplotlib, показывающая, какие темы являются самыми массовыми, а какие — редкими.
